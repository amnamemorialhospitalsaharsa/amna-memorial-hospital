🔐 Admin Panel V2 — Secure Architecture

Secure login, database और controlled content editing के लिए proposed technical architecture.

Security rule: Admin password, database credentials और patient data को public GitHub Pages code में नहीं रखा जाएगा। V2 का secure backend अलग protected service पर होना चाहिए।

🏗️ V2 Architecture

1. Admin LoginSecure authentication और session management.
2. Backend APIAuthorized requests को validate और process करेगा.
3. DatabaseApproved website configuration/content को securely store करेगा.
4. Public WebsitePublished content को backend से read करेगा.

👥 Roles & Access

RoleAccessPurpose
Super AdminFull controlSystem settings, users, publishing and audit
AdminContent + OPDDoctors, services, schedules and updates
ReceptionOperationalOPD/appointment coordination and approved updates
EditorLimited contentDraft content and images; no security settings

✏️ Content Editing Modules

DoctorsName, profile, specialty, OPD timing and availability.
OPD ScheduleDaily/temporary availability and schedule updates.
ServicesService title, description and page status.
Hospital UpdatesNotices and announcements with publish status.
ImagesApproved gallery/website images and metadata.
WhatsAppApproved contact number and message templates.

🛡️ Security Controls

AuthenticationPasswords handled only by secure authentication service.
AuthorizationRole-based permissions for each admin action.
SessionsSecure session expiry and logout.
Audit LogImportant edits record who changed what and when.
BackupControlled backups before major changes.
RecoveryAdmin recovery process kept separate from public site.

🏥 Patient Data & UHID Boundary

Admin Panel V2 website content management के लिए है। Patient medical records और hospital का existing UHID system इससे अलग authoritative system रहेंगे। Website नया UHID automatically generate नहीं करेगी। किसी future patient-data integration को अलग secure access controls, database design और hospital approval के साथ बनाया जाएगा।
